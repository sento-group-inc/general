Skillは、AIに毎回同じ進め方をさせるための手順書です。  
プロンプトを毎回頑張るのではなく、よく使う型をスキルとして呼び出します。

対象はこちらです。  
[mattpocock/skills の productivity セクション](https://github.com/mattpocock/skills/tree/main/skills/productivity)

## まず使えるようにする

下のプロンプトをそのままCodexに貼る。  
自分でリンクを読んで選ばなくても、まず外部の4つのSkillを使える状態にするための依頼です。振り返り用の `reflect` は、この研修用に別途用意したSkillとして後半で使います。

```text
https://github.com/mattpocock/skills/tree/main/skills/productivity にある4つのSkill、grill-me、handoff、teach、writing-great-skillsを私の環境でSkillにして使えるようにして。
```

<StepFlow>

## 本編で使うSkill手順集

| Skill | 使う場面 |
|---|---|
| [grill-me](/day-1/skills/grill-me/) | 何を作るか、何が詰まりか、判断の枝を深掘りしたい |
| [handoff](/day-1/skills/handoff/) | 次の人・次のセッションに文脈を渡したい |
| [teach](/day-1/skills/teach/) | 1回の回答ではなく、学習を積み上げたい |
| [writing-great-skills](/day-1/skills/writing-great-skills/) | 自分用Skillを作る、既存Skillを直す |
| [reflect](/day-1/skills/reflect/) | セッション終わりに learning-log/ へ記録する |

<Callout variant="tip" title="研修での見方">
  ここではSkillを暗記しない。どの場面で呼ぶと仕事が進むかだけ押さえる。
</Callout>
