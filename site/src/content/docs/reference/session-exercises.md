# セッション別「やってみることまとめ」＆おかわり課題

各セッションに、(A)やってみることのまとめ、(B)早く終わった人向けのおかわり課題 を置く。進度のバラつき（部署混在15名）を吸収し、速い人を遊ばせない。バディ制（先に通った人が隣を助ける）と併用。

---

## Day1 AM｜性格診断HTML

**やってみること**
- Codexで `hello.md` を作る（動作確認）。
- 30分の自由探索：趣味・旅行・料理・学習など、仕事以外の自分の興味から1つ試す。最後に「意外にできたこと」を隣の人と共有する。
- ホロスコープ（[鏡リュウジ](https://kagamiryuji.jp/horoscope/)）の画像＋動物占い（[aoi-project](https://aoi-project.com/animal/)）をCodexに渡し、自分の取扱説明書をHTMLで出力。

**おかわり課題**
- 色・レイアウトを指示して見た目を変える。
- 「他人に渡す用」に1枚にまとめ直す。
- 占いをもう1種足して、統合の精度が上がるか試す。

---

## Day1 PM｜習熟＋練習制作

**やってみること**
- 習熟：AGENTS.md・設定・自分用スキルを1個作る・振り返りskillを1回回す。
- ミニデモ：GitHubリポジトリのURLを渡して「これ使えるようにして」。
- 練習制作：**タスク管理（ToDo）アプリをHTML/CSS/JSで作る**（参考: [mescius quickstart](https://devlog.mescius.jp/ai-agent-codex-quickstart/)）。プロンプト例「HTML・CSS・JavaScriptで、シンプルなToDoリストアプリを作って」。ブラウザで動作確認。

**おかわり課題**
- ToDoに「完了チェック」「削除」「並べ替え」「ローカル保存」を足す。
- 配色やUIを指示して整える。
- `/plan` を使って、作る前に計画を立てさせてから実装させる。
- 自分の業務の小さな作業を1つHTML化してみる。

---

## Day2 AM｜TOC業務棚卸し

**やってみること**
- 制約から「何を・どの順で」やるか洗い出し → ロードマップ＋実施事項TSV。
- 自分の担当（作るアウトプット／スキル）を決める。

**おかわり課題**
- 自分の棚卸し結果をCodexに渡して、優先順位の理由を整理させる。
- 担当アウトプットのインプット（過去フォーマット・参考資料）を先に集めておく。

---

## Day2 PM｜本制作

**やってみること**
- 分担したアウトプットを仕上げる。`/plan` → 制作 → `/review`。
- 振り返りskillで記録 → AI活用100選HTMLに反映。

**おかわり課題**
- 2つ目のアウトプットに着手。
- 自分の作ったものを「部署で再利用できる型（テンプレ／プロンプト）」に一般化する。
- うまくいった指示を AGENTS.md に永続化する。
