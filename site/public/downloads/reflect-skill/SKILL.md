# 振り返りskill（reflect）

セッションの区切りで実行する。活動ログは `learning-log/` に書き、AGENTS.md には昇格候補だけを提案する。

## いつ使うか

- 1つの演習が終わったとき
- Day1 / Day2 のセクションを抜けたとき
- 詰まって直した直後
- 発表前の整理

## やること

1. 今日の `learning-log/YYYY-MM-DD.md` を開く（なければ作る）
2. 次の4項目を追記する
3. 同じミスを2回繰り返したら、AGENTS.md への追記案を1行だけ出す（本文には書かない）

## 追記フォーマット

```markdown
## [セッション名] HH:MM

### できたこと
-

### 詰まったこと
-

### どう直したか
-

### 使えた型（プロンプト・手順・Skill）
-

### 明日試すInput / Process
-
```

## ルール

- 失敗は「次の教材」として書く。省略しない
- AGENTS.md に生ログを書かない
- 再利用できるルールだけを「AGENTS.md追記案」として別行で提案する
- APIキー・パスワード・本番の秘匿情報は書かない

## 実行プロンプト（Codexに貼る）

```text
/reflect を実行してください。
いま終えたセッションの振り返りを learning-log/YYYY-MM-DD.md に追記してください。
項目は「できたこと」「詰まったこと」「どう直したか」「使えた型」「明日試すInput/Process」。
同じミスを2回繰り返している場合だけ、AGENTS.mdへの追記案を1行提案してください。AGENTS.md本文はまだ書き換えないでください。
```
