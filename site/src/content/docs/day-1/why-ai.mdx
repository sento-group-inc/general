道具は、使いこなすほど「道具を使っている感覚」が消えます。自転車や車の運転と同じで、慣れると意識から消えて、身体の延長になる。これが **拡張感覚** です。AIも同じで、操れるようになると思考の延長になります。

## チャットでよくない？ — 口だけのAIと、手も動くAI

「ChatGPTみたいなチャットでよくない？」と思うかもしれません。半分はその通りで、調べ物や下書きの多くはチャットで足ります。

違いは **入力のしやすさ** ではなく **出力と実行** にあります。

<BenefitCards
  items={[
    { title: 'チャット＝相談相手（口だけ）', text: '会話の中に答えが出る。最後は自分がExcelを開いて打ち込む。' },
    { title: 'コーディングエージェント＝部下（手も動く）', text: 'Excelやスライドそのものを作ってフォルダに置く。資料や図が現物で残る。' },
  ]}
/>

- **現物が残る**：会話のテキストではなく、ファイルが手元に残る。
- **資料を横断できる**：フォルダ丸ごと（議事録・過去フォーマット）を読んで作業する。
- **外部ツールに手が伸びる**：Box / SharePoint / Excel に取りに行く・書きに行く。
- **段取りを再利用できる**：よく使う手順を覚えさせる（＝Skill）。

<Callout variant="tip" title="「コードが書ける」の意味">
  非エンジニアにとっての価値は、コードを書くこと自体ではありません。Excelの集計もHTMLの可視化もデータ整形も、すべてコードの上で動いています。コードという万能の手を持っているから、何でも作れて何でも触れる。だから「最強のAI」と言えます。
</Callout>

チャットが詰まるのは「現物のファイルが欲しい」「大量の資料を横断したい」「同じ作業を繰り返す」の3場面。今日の午後は、まさにこの場面を自分の手で体験します。
