`/grill-me` は、「まだ曖昧な計画や設計を、質問で詰め切る」ためのスキルです。  
1回の回答で結論を出すのではなく、決定ツリーの枝を一つずつ解きます。

元スキル: [grill-me / SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md)

## 何をするスキルか

あなたが「この計画をグリルして」と言ったとき、エージェントは遠慮なく質問します。

- 目的は何か
- 誰のためのものか
- どこが未決か
- 何を先に決めるべきか
- どの選択肢が筋良で、どれが筋悪か

## 何が残るか

`grill-me` は、会話の中で出た論点を整理し、次の作業に使える状態へ近づけます。

| 残るもの | 役割 |
|---|---|
| 決定事項 | 何を採用するか |
| 未決事項 | まだ決めていないこと |
| 却下案 | なぜ選ばなかったか |
| 次の一歩 | 今日動ける作業 |

## 通常のチャットとの違い

| 通常 | /grill-me |
|---|---|
| すぐ答えを返す | 先に質問して曖昧さを潰す |
| 質問が浅く終わる | 決定の依存関係まで見る |
| その場の相談で終わる | 次に動ける形へ整理する |

一言で言うと: `/grill-me` は「答えを出す」より先に、「何を決めるべきか」を明らかにするスキルです。

## 使うなら

```text
この業務改善案を /grill-me で詰めたい。質問は推奨回答つきで出して。
```

```text
この研修ページの目的が曖昧なので、/grill-me で論点を分解して。
```
