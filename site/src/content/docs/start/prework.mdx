受講者PCはWindows前提で進めます。**Codexデスクトップアプリ**を使い、Cursor等のIDEは不要です。WSLも必須ではありません。

## 0. Codexアプリの導入（事前または当日）

Microsoft Store または winget から Codex をインストールします。

```powershell
winget install Codex -s msstore
```

インストール後、ゼネラルの有料ChatGPTアカウントでサインインします。  
Node.js や Python は Codex 本体の必須条件ではありません。必要な演習（crawl4ai 等）のときだけ個別に入れます。

<Callout variant="warn" title="最大の詰まりポイント">
  社内プロキシやTLS設定でサインインが失敗することがあります。事前にインストールとサインインまで済ませておくと当日が楽です。
</Callout>

<StepFlow>
  <Step no="1" title="Codex App にログイン">ゼネラルの有料ChatGPTアカウントでCodexにログインする。</Step>
  <Step no="2" title="研修フォルダの作成場所を確認">SharePoint上に `AI研修_氏名` を作ることだけ確認する。実作業はAGENTS.mdパートでまとめて行う。</Step>
  <Step no="3" title="Codex設定を確認">左メニュー、一般設定、作業モード、権限、音声、通知、パーソナライズを確認する。</Step>
  <Step no="4" title="動作確認">後続のAGENTS.mdパートで `learning-log/`、`outputs/`、`hello.md` を作れるように準備する。</Step>
</StepFlow>

<Callout variant="check" title="最短ゴール">
  当日朝に詰まらず、すぐ手を動かせる状態にする。開発者向けの準備ではなく、業務資料を扱うための箱と、Codexを安全に使う初期状態を作る。
</Callout>

## 1. 研修フォルダと記録ルールはAGENTS.mdパートで作る

SharePoint上の研修フォルダ名は、次の形にそろえる。

```text
AI研修_氏名
```

ただし、このページでは詳細な作成手順まで進めません。`learning-log/`、`outputs/`、`AGENTS.md`、`hello.md` の作成は、[AGENTS.mdでログを貯めて失敗も成功も資産にしよう](/day-1/agents-logging/) でまとめて実践します。

ここでやることは、Codexにログインして、SharePointの場所を開けるか確認するところまでです。

## 2. 作業フォルダを固定する

Codexの入力欄下にあるプロジェクト選択から、今回使う作業フォルダを固定します。ここが毎回ぶれると、`AGENTS.md`、`learning-log/`、`outputs/` が別の場所に作られてしまいます。

<ImageText

  title="既存のフォルダーを使用"
  caption="プロジェクト選択から研修フォルダを固定する"

  <ul>
    <li>入力欄下のプロジェクト名（例：general）をクリックする</li>
    <li>一覧に `AI研修_氏名` があれば選択する</li>
    <li>なければ **既存のフォルダーを使用** から研修フォルダを選ぶ</li>

  </ul>

<Callout variant="check" title="ここで固定する理由">
  Codexは選んだプロジェクトフォルダを作業場所として扱います。研修では `AI研修_氏名` を固定し、成果物は `outputs/`、記録は `learning-log/` に集めます。
</Callout>

## 5. 作業モードと権限を確認

<ImageText
  imageSrc={workmodeShot.src}
  imageAlt="作業モードと権限"
  title="作業モードと権限"
  caption="作業モードはコーディング向け。権限は必要な時だけ広げる"

  <ul>
    <li>作業モード：Codexがどの前提で作業するかを決める設定</li>
    <li>読み取り中心：まず調べるだけの時に使う</li>

権限は、ローカルで実行するコマンドやファイル操作の範囲を決めるものです。外部サービス、ブラウザ操作、コンピュータ操作、プラグインはそれぞれ別の接続・承認で管理されます。

## 7. パーソナライズ、カスタム指示、メモリを確認

  caption="カスタム指示、メモリ、個人設定の画面"

    <li>メモリ：過去の有用な文脈を次回以降に使う機能</li>
    <li>パーソナライズ：表示名や個人設定を管理する場所</li>
  </ul>
</ImageText>

### カスタム指示とは？

Codex全体に効く、基本の振る舞い定義です。口調、回答の長さ、確認の仕方、禁止事項を先に書いておくと、毎回同じ注意をしなくてよくなります。貼り付け文は [おすすめカスタム指示](/reference/custom-instructions/) を使います。

### メモリを有効にするとは？

過去スレッドから有用な文脈をローカルのメモリとして保存し、次回以降の作業で使えるようにする設定です。便利ですが、研修中は `learning-log/` を正本にします。メモリに頼らず、人間も読める形で記録を残すためです。

## 8. 動作確認

CodexでSharePointの研修フォルダを開けるところまで確認する。ファイル作成の本番確認は、次のAGENTS.mdパートで行う。

```text
このあとAGENTS.mdパートで、AI研修_氏名 フォルダに learning-log/、outputs/、AGENTS.md、hello.md を作ります。
いまはこのフォルダを作業場所として扱えるか確認してください。
```
